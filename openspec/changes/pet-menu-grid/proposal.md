# proposal: 桌宠右键改成「图标格子菜单」

## 要解决什么

用户的原话：

> 宠物右键的界面不要跟托盘一样啊，需要跟对话框一样的风格的界面，格子布局，
> 每个格子一个图标指向一个功能，有对话，设置，插件，日程等。

现状（2026-10-26 起）是：右键桌宠 → `App.OpenPetMenu()` → `a.tray.ShowMenuAtCursor()`
→ 托盘线程 `TrackPopupMenu`。也就是说，**右键桌宠弹出的就是托盘图标那一份原生菜单**：

- 两个手势长得分毫不差：浅色系统菜单、灰色文字、没有图标、没有分组，和桌宠的深色卡片
  （`rgba(28,30,36,.94)` + 圆角 + 12px 内边距）一点关系都没有；
- 一条竖列放不下越来越多的动作，也没有"分组"这个概念——只能靠分隔线；
- 它对宠物说的话、宠物正在做的事一无所知：同一个动作在菜单里叫「开启/关闭番茄钟」，
  而用户看不出现在到底是开还是关。

## 做什么

右键桌宠弹出一张**和气泡一模一样的卡片**（同一个 `#bubble`、同一个矩形、同一个圆角），
卡片里是 **3×3 的格子**，一格一个图标 + 一个词：

| 格 | 动作 | 调用的绑定 |
| --- | --- | --- |
| 日程 | 打开待办面板（带截止时间的那张表就是本程序的"日程"） | `SetPanelOpen(true)` |
| 对话 | 打开对话插件的浮层面 | `OpenChatPluginSurface()` |
| 番茄钟 | 开启 / 关闭（与托盘项、面板按钮同一个开关） | `SetPomodoroEnabled(!enabled)` |
| 提醒 | 立刻提醒一次 | `RemindNow()` |
| 插件 | 启动控制中心（插件页） | `OpenPluginMarket()` |
| 设置 | 启动控制中心（偏好设置） | `OpenPluginMarket()` |
| 归位 | 回到默认位置 | `ResetToDefaultPosition()` |
| 隐藏 | 隐藏桌宠（快捷键 / 托盘叫回来） | `HidePetForUser()` |
| 退出 | 退出 PetPC | `Quit()` |

收起的方式有五种，全部沿用已有机制：再右键一次（`togglePetMenu`）、`Esc`（气泡的
Escape 链）、窗口失焦（新增，见 design 5）、选一个格子、以及**任何会在同一槽位打开东西的
动作**（开面板 / 开浮层面 / 隐藏 / 拖动 / 番茄钟换相位——Go 侧折叠气泡时顺带把它收掉）。

## 明确不做

- **不做第四个占位。** 菜单是 `BubbleMenu`，气泡的一种 kind：它借气泡的矩形、裁剪和"同一位
  置只放一个"的折叠规则。`app.go` 的 region switch、`Layout`、`AGENTS.md §3.2` 一行未改。
- **不动托盘菜单。** 托盘右键仍是原生菜单：它是**程序级**的入口清单，而且是宠物被隐藏时
  唯一的路（`app_hotkey.go` 的注释就是这么写的）。这次只换"桌宠自己"的手势。
- **不做控制中心的深链接。** 控制中心（`PetPCPluginMarket.exe`）不接受命令行参数，页签是
  Svelte 的本地状态（`tools/plugin-market/cc/src/App.svelte`）。所以「插件」和「设置」是
  同一程序的两扇门，各自在 `title` 里说清是哪半。为了一格而给控制中心加参数解析，是这次
  不需要的耦合。
- **不把格子的动作在 Go 里再列一遍。** 每格调的都是这个动作本来就有的绑定，所以不再存在
  "菜单里的番茄钟"和"托盘里的番茄钟"两份实现。
- 不给卡片加阴影 / 位移 / 翻转动画（`transform` 会让像素在过渡中途伸出裁剪框，
  `style.css` 顶部与 §3.2 都写过这条）。

## 影响的不变量

- `AGENTS.md §3.2`「面板 / 气泡 / 插件浮层面共用一个槽位，一屏只有一个」**不变**，但多了一句
  需要记住的话：**菜单是气泡，不是第四种占位**。写进 `AGENTS.md §3.2` 与
  `app_pet_menu.go` 的文件头。
- 提问待答时菜单**不许开**：它会"顶掉"而不是"盖住"那张问题卡，而总结提示卡着休息、计划
  提示卡着下一段专注。后端 `OpenPetMenu` 拒绝，前端 `togglePetMenu` 把光标送进问题框
  （`focusAnswer`）——和对话按钮同一套规矩。
- 区域仍是**矩形包围盒**：卡片圆角外那几像素仍然落回本窗口（`§3.2` 记录的代价），和面板、
  气泡一致，不因这次改动而变。
- 守门检查同步改（新增/替换，不是删掉）：`.dev/check-frontend.cjs` 里"原生弹出菜单"那条
  整块换成页面菜单五条；`.dev/run-frontend-harness.cjs` 与 `.dev/harness-checks.js` 的
  右键场景改成"格子真的画出来了、再点一次收起"；新增 `app_pet_menu_test.go` 与
  `frontend/src/pet-menu.test.js`。

## 验证计划

- `go test . -run 'PetMenu|OpenPetMenu'`：卡片尺寸是冻结的 226、"打开后 state 与 layout
  都记着它"、开菜单会折叠面板与浮层面、提问待答时拒绝且什么都不改、`DismissBubble` /
  开面板 / 相位切换都能收起它。
- `cd frontend && npm test`（新增 `pet-menu.test.js` 22 例）：九格的 `data-menu` 与图标/文字、
  右键调 `OpenPetMenu`、卡片渲染出格子且别的部件被清空、每格调对绑定、再右键/Esc/失焦
  都会收起、三个提问气泡在时右键不调 `OpenPetMenu`。
- `node .dev/check-frontend.cjs`：接线五条 + 托盘不再被借用的反向断言。
- 真机：右键桌宠 → 卡片出现在宠物旁边、九格可点；选「日程」面板打开；再右键一次收起；
  点别的窗口（失焦）收起；番茄钟等你写总结时右键 → 光标进输入框、菜单不出现。
