# proposal: 对话浮层面拆成三块固定盒子——提问 / 回复 / 输入

## 要解决什么

浮层面现在是**两块、三用途**：块 0（92px 回复卡）有时画提问、有时画回答，块 1（66px 胶囊）
有时是输入框、有时是"等待回答…"的结果区。用户看下来的原话是：

> 对话框显示的流程还是有问题。

把流程拆开看，实际发生的事情是：

1. 发送后，**块 1 变成结果区**显示 `等待回答…`；
2. 块 0 读转写后画的是**用户自己的提问**（还带着 `.msg.user` 的蓝底、右对齐、贴底），
   于是一个 92px 的盒子里只有右下角一个蓝色气泡；
3. 答案在块 1 里逐字打出来，块 1 只有 56px、`justify-content: flex-end` + `overflow: hidden`，
   所以超出部分**从顶部被切掉**；
4. 打字结束（50ms/字）后发送帧才写转写，块 0 靠 **800ms×60 的轮询**读回来，才把提问换成答案。

同一个答案出现了两次、顺序颠倒，而"上面那块"和"下面那块"在中途讲的是两件不同的事。
根因不是某一处画错，而是**一块盒子会改变用途**：谁画什么只能在运行时判断（`isCardBlock()`、
`visibleComposer()`、`rectIndex` 三重猜身份），而"换成"这件事只能靠磁盘往返实现。

## 做什么

把用途固定成**三块盒子，一块一个用途**，全靠声明而不是运行时判断：

| 块 | 用途 | 尺寸（逻辑 px） | 位置 |
|---|---|---|---|
| 0 | 提问框，**只画最后一条用户提问** | 300 × 48 | 宠物头顶最上方 |
| 1 | 回复框，**只画当前/最后一条回答**，带朝下尖角 | 300 × 100（90 气泡 + 10 尖角带） | 紧贴宠物头顶 |
| 2 | 输入框，只画输入框 | 300 × 56 | 宠物**脚下**，无尖角 |

- 角色由 `surface.rectIndex`（声明下标）决定，且**三块都常显**：不再调用 `surface.blocks`。
- 提示/回答的时序变成纯事件驱动：回复框自己收 `llm.delta`/`llm.done` 直播，
  `done` 一落地就把权威全文校正上去；转写在 `done` 当场写，**不再等打字机**。
- 提问框每轮只读一次转写（`storage.get`），没有轮询。
- 答案长高这件事**整体放弃**（`maxH`、`surface.blocks` 的 `sizes`、`requestCardHeight`
  一并去掉）：头顶只有 160px，长高一定是死路；超出就截断，全文去面板看。

## 明确不做

- **不让插件提交坐标或尺寸**（`surface.blocks` 的既有边界不变）。
- 不做"运行时改清单"：三块是编译期固定的声明，变的是**内容**，不是几何。
- 不改宿主的 `hidden`/region 语义。这一版**三块常显**，因此不触发"隐藏即重建全部 iframe"
  那条已知缺陷（见 design §5"为什么现在还不能只改隐藏/显示"）。
  > **【已跟进】** 下一步 `surface-hidden-keeps-frames` 修掉了那条缺陷，浮层面因此可以在空闲时
  > 只显示输入框。
- 不做"回答框长出宠物头顶"、不做滚动条、不做主动说话。

## 影响的不变量

`AGENTS.md §3.2`（面板/气泡/浮层面同一时刻只有一个可见）不变：变的是浮层面**内部**有几块、
每块画什么。区域仍是这三块 + 宠物的并集，区域与绘制由同一次 `computePluginSurfaceSized`
算出，没有第二份几何。

## 已知边界（必须随代码一起记住）

- **头顶预算固定 156/160**：`petY = (520 - 200×PetScale)/2`，默认 `PetScale=1` 时头顶 160px，
  三块里上方两块占 156px。`PetScale` 一旦超过约 1.04，提问框顶边会被窗口顶边裁掉
  （今天是同样的机制在裁掉回复卡的 6px）。
- **输入框的 `dy` 是相对宠物**左上角**量的**，写死 208（= 宠物高 200 + 间隙 8），
  所以它只在 `PetScale=1` 时正好贴在脚下。`PetScale` 变了它就会压到宠物身上。
  真要做成与宠物大小无关，manifest 需要一个"锚定宠物底边"的字段——那是宿主改动，
  这一版刻意不做，见 design §6。

## 验证计划

- market（独立仓库）：`npm test`——三块视图的角色、提问框只画提问、回复框只画回答且直播、
  输入框不再是结果区、`done` 立即落盘、manifest 三段几何与预算断言。
- 宿主：`go vet ./...`、`go test ./...`（`internal/plugins/sample` 的字节与目录同步后）。
- 前端：`cd frontend && npm run build && npm test`、`node .dev/check-frontend.cjs`。
- 真机：装插件重启桌宠，看三段盒子各自的形状、尖角只在回复框上、发送→提问上移→回答在下面直播。
