# tasks: 界面重建

## 阶段 1｜地基：设置与运行时分离（不做界面）

目标：让「控制中心改设置 → 运行中的桌宠立刻看到」成立，且**不存在丢更新**。

- [ ] `internal/store`：把持久化拆成 `settings.json`（偏好）与 `config.json`（运行时：
      位置、大小、吸附边），`Config()` 在内存里合并两份
- [ ] 首次加载时迁移：老 `config.json` 的偏好键**复制**进 `settings.json`，老文件原样
      保留（读失败时回退），不删任何键
- [ ] `Config()` 加 mtime 检查（节流 500ms），文件变了就重读并合并
- [ ] 桌宠侧不再写偏好键：`UpdateConfig` 只落运行时字段
- [ ] 测试：`settings.json` 改动后 `Config()` 返回值变化；桌宠写位置不会覆盖设置；
      迁移后老配置的每个键都还能读到

**验收**：手工改 `settings.json` 的番茄时长，运行中的桌宠下一次 tick 就用新值。
