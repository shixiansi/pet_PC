# 语音朗读

桌宠会说话，说**固定台词**。

## 现在是什么

番茄钟结束、待办提醒弹出时，桌宠用游戏角色的声音说一句预录好的话。

| 台词 | 什么时候说 |
|---|---|
| 专注时间结束了，起来活动一下吧。 | 专注阶段结束 |
| 休息结束了，我们继续吧。 | 休息阶段结束 |
| 有些事情到期了，记得看一下。 | 有今天到期的待办 |
| 有事情已经逾期了，记得处理一下。 | 有待办逾期 |
| 现在没有待办，好好休息吧。 | 提醒触发但列表为空（需显式开启） |

5 条，合计 **569 KB**，用**可莉**音色。

> **内置音色是"可莉"，这是构建时的事实**：这 5 个音频烤在 exe 里
> （`internal/voice/lines/*.wav`），重新构建才会变。
>
> 想换成别的角色，用**配音工坊**（一个独立程序，见 `docs/voice-studio.md`）。
> **在工坊左栏点一下角色，桌宠随即就用那个音色** —— 选中态就是播放源。
> 该角色**还没录过的句子**不会退回内置音色（那会让你听到一个界面上没显示的角色），
> 而是**不出声并在工坊里标成「待生成」**，点「整套换成这个角色」即可补齐。
> 播放机制不变 —— 都是读一个 WAV 文件。

## 三个关键性质

**即时** —— 音频**内嵌在 exe 里**（`internal/voice/lines/*.wav`，`go:embed`）。
播放就是读一个文件然后交给 winmm，没有合成、没有网络、没有排队。实测**毫秒级**。

**离线** —— 不联网、不需要任何服务、不需要装 GPT-SoVITS，也不占内存。
（配音工坊**生成时**需要本地引擎，但播放永远不需要。）

**稳定** —— 每次播放的字节完全相同。不存在"这次读得好、下次读得怪"。

## 设置

设置 → 语音朗读：

| 开关 | 默认 | 理由 |
|---|---|---|
| 让桌宠在提示时说话 | **关** | 默认不发任何声音 |
| 朗读番茄钟提示 | **开** | 计时器是**你自己启动**的、正在等的，出声是预期之内 |
| 朗读待办提醒 | **关** | 提醒可能在**开会时**触发，桌宠突然出声比气泡滑入侵入性强得多 |

另有「试听」（忽略两个通知开关，只为让你先听到声音）和「停止」。

## 台词里为什么没有数字

提醒语说"有些事情到期了"，**不报具体数量**。

固定音频**没法临时拼数字**（除非预渲染 1~99 共几百个文件），
而具体数字**气泡里就写着**。说话的作用是"你没看屏幕时也知道有事"，
这一点不带数字也能传达。

## 换角色 / 改台词

**在配音工坊里换**：桌宠面板 → 设置 → 语音朗读 → **打开配音工坊（换音色）**。

配音工坊是一个**独立的程序**（`tools\voice-studio\`），有自己的窗口，分两栏：

- **左栏角色**：点一下**就是切换**，桌宠随即用那个音色（不需要重启任何一个程序）。
- **右栏台词**：每条显示「现在：…」徽章，说明**此刻桌宠会说什么**。

两种"换"要分清楚：

| 动作 | 效果 |
|---|---|
| 左栏**点角色** | 立刻换音色。该角色没录过的句子**不出声**，标成「待生成」 |
| **整套换成这个角色** | 5 条全部生成**并采用**，等于把这个角色当成新的"内置音色" |
| 逐句**生成** → **用这版** | 只对那一句生效；**生成本身不会采用** |

完整说明见 **`docs/voice-studio.md`**。

> 它独立出来是因为**面板太拥挤**：面板是固定 380×520 的矩形（窗口区域按它裁剪，
> 不能长大），而配音是 5 条台词 × 每行多个版本的工作面，塞不下。
>
> 构建两个程序：`pwsh -File tools\build-all.ps1` —— 它会把工坊的 exe
> 复制到桌宠旁边（桌宠就是在那儿找它的）。

### 重新渲染内置台词（改文字时）

改台词文字要改 `internal/voice/voice.go` 的 `Texts`，然后重新渲染内置音频：

```powershell
# 1. 起桥接（先用哪个角色都行，脚本会按名字去取）
powershell -ExecutionPolicy Bypass -File _archive\tts-realtime\tools\tts-online\start-bridge.ps1

# 2. 重新渲染全部台词（角色名要与服务端一致，见桥接的 -ListVoices）
python tools\voice-fixed\make_lines.py "可莉"

# 3. 重新构建
wails build
```

> **角色名必须精确**：服务端用「纳西妲（草神）」而不是「纳西妲」，
> 名字错了**不报错，只返回空音频**。用 `-ListVoices` 查准确名字。

> 改台词文字时**记得同步两处**：`internal/voice/voice.go` 的 `Texts`
> （App 实际用的）和 `tools/voice-fixed/make_lines.py` 的 `LINES`
> （在线渲染脚本用的）。另外 `voice.go` 的 `BuiltInRole` 要跟着改，
> 界面靠它显示"内置是哪个角色"。

## 实现要点

**内嵌但走文件播放**：`SND_MEMORY` 要求调用方缓冲区在整个异步播放期间存活，
而 Go 的 GC 不知道这件事 —— 一次回收就会静音或崩溃（约 1% 概率）。
所以 `internal/voice` 把字节写成一个文件再按路径播放。

**文件名带内容哈希**（`petpc-<line>-<sha1前6字节>.wav`）：
重新渲染后字节变了、文件名也变，**不会播放到旧版本**。
旧文件由启动时的 `voice.Cleanup` 回收，且**只删自己命名规则内的文件**。

**缺文件是构建问题**：`go:embed` 没匹配上时，启动日志会打印
`voice: enabled=true lines=5 missing=N`。测试 `TestEveryLineIsEmbedded`
会在构建阶段就抓到。

## 实时合成哪去了

曾经有一套实时合成（朗读对话回复），已**停用并归档**在 `_archive/tts-realtime/`。

停用原因：**太慢**（54 字要 11 秒）、**太重**（本地模型 3.3GB）、**不稳定**（上游输出随机）。
详见 `_archive/README.md`，里面有完整的踩坑记录和恢复步骤。
